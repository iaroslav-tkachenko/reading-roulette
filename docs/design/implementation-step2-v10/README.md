## Изменения

В существующие SVG-поля встроены три нативных HTML select через foreignObject. Они масштабируются вместе с машинкой; сохранены координаты подписей, рамки, фон полей и отдельные стрелки. Закрытый список использует Georgia размером 24 единицы сцены. Открытое меню системное, его оформление зависит от браузера. Фокус клавиатуры обозначен контуром. У каждого списка есть доступная видимая подпись; SVG имеет роль группы, чтобы не скрывать рабочие контролы внутри единого изображения.

Настройки хранятся в App в одном useState. После выбора из списка buildPrompt пересчитывает полный текст, передаваемый PromptSheet. Комбинация Travel / Short story / Unexpected discovery сохраняется. Начальное состояние — English / B1+ / Medium. Недопустимые значения обработчики отклоняют.

По дополнительной просьбе пользователя восстановлен исходный набор из [11 языков](../../LANGUAGES.md): English, Spanish, French, Japanese, German, Korean, Italian, Chinese (Mandarin), Russian, Portuguese, Serbian. Первоначальное обсуждение найдено в истории проекта от 2026-10-09; список не восстановлен догадкой. В поле Chinese используется короткая подпись, полное название находится в подсказке и промпте.

Все 15 уровней и три длины используют [согласованную таблицу](../../LEVELS_LENGTH.md): A1 / A1+ / A2− — 40–80 / 100–150 / 200–300; A2 / A2+ / B1− — 60–100 / 150–250 / 300–450; с B1 — 100–150 / 250–350 / 500–700 слов. Уровни с плюсами/минусами сохраняют собственные языковые инструкции. Одна функция getTextLength используется в поле длины, доступном описании, подсказках вариантов и полном промпте. Новая строка под полями не добавлена.

Для Japanese и Chinese (Mandarin) применено правило документа для неоднозначного подсчёта слов: относительная длина и структурная инструкция вместо численного диапазона слов/знаков. Остальные специальные модели объёма внедряются вместе с полным каталогом форматов на шаге 10. Состояние перед дополнением языков и диапазонов сохранено в before-catalog-settings/.

Промпт остаётся доступным полностью для выделения и обычной прокрутки страницы. Комната, стол, механика, SPIN, клавиши и бумага сохраняют геометрию v10. How to use, SPIN, Copy prompt и анимация относятся к следующим этапам. Состояние изменённых файлов перед этим шагом сохранено в before/.

## Что теперь можно проверить

1. Открыть рабочее приложение при обычном масштабе: начальные значения English / B1+ / Medium.
2. Выбрать German: первая строка промпта должна содержать German; барабаны сохраняют Travel / Short story / Unexpected discovery.
3. Выбрать A2 или C1: строка Difficulty target и следующие рекомендации должны соответствовать выбранному уровню.
4. Для English / Medium переключить A1 → A2 → B1: строка Length и подсказка поля должны показывать 100–150 → 150–250 → 250–350 слов. B1− должен давать 150–250, A2− — 100–150. Для B1 / Short и Long ожидаются 100–150 и 500–700 слов.
5. Вернуться к English / B1+ / Medium и сверить исходный текст. Пройти поля через Tab и изменить выбор стрелками/Enter; стандартные клавиши меню зависят от браузера.
6. Прокрутить лист до конца и выделить текст. Проверить, что меню выходит поверх сцены и что изменение настроек не сдвигает машинку.
7. Выбрать Russian, Portuguese и Serbian: первая строка промпта должна использовать соответствующий язык. Выбрать Japanese или Chinese: инструкция Length должна описывать относительную длину и структуру, без диапазона слов или знаков. Вернуться к English — численный диапазон восстанавливается для текущего уровня.
