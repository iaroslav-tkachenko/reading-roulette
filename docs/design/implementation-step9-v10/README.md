## Изменения

Оба боковых колеса получили отдельный слой движущихся насечек. Использован повторяющийся фрагмент исходной латунной фактуры wheel-v1.png внутри маски обода с плавными краями. Наружная форма, боковая плоскость, ось, крепёж и координаты оригинальных PNG сохраняются. Вытянутый силуэт колеса не поворачивается в плоскости экрана. Никаких новых PNG или зависимостей.

Обода запускаются на общей временной шкале с барабанами: задержка 100 мс, разгон 140 мс, быстрый ход 1860 мс, плавное торможение 340 мс. Полная остановка — на 2440 мс, одновременно с последним барабаном. Торможение идёт только вперёд. За цикл фактура проходит 12 периодов; это число насечек, а не оборотов колеса. Отдельной задержки выдачи результата нет. Существующие два перемешанных прохода всех 19 клавиш сохранены.

При прерывании сохраняется текущий сдвиг фактуры до отмены эффекта. Следующий SPIN продолжает эту фазу. Сдвиг уменьшается только на целое число периодов, поэтому видимая позиция не меняется. Завершение, скрытие вкладки, resize, размонтирование и защитный таймер используют общий cleanup. Ошибка декоративного колеса не заставляет барабаны остановиться раньше. При reduced motion контроллер выдаёт результат сразу, не запуская барабаны, клавиши или колёса.

React не обновляет состояние на каждом кадре: движение выполняет Web Animations API. Фон, стол, лампа, книги, стакан, корпус, рама и лист не анимируются. How to use по-прежнему ожидает уточнения текста. Полные каталоги относятся к следующему этапу.

## Дополнение: плавные указатели на шарнирах

После пользовательского просмотра частые щелчки заменены плавным отводом стрелки и возвратом к барабану. Ориентир — [подпружиненная собачка храповика](https://www.notesandsketches.co.uk/Ratchet.html): движущаяся поверхность отводит указатель, пружина возвращает его к поверхности. Это стилизованное движение с редкими крупными ходами.

Шесть наконечников вырезаны из исходного PNG и закреплены на четырёх неподвижных шарнирах. Каждый средний ромб разделён на две независимые стрелки для соседних барабанов. Добавлены короткие латунные ножки и небольшие винты. Размер и координаты исходной рамы сохранены.

По следующему пользовательскому скриншоту исправлен фон: треугольные маски удаляли вместе с наконечниками участки дуг, через которые просвечивала бумага. Теперь четыре неподвижных участка фона восстанавливаются из чистой полосы исходного PNG непосредственно под стрелками (y=444–462). Они продолжают металлические стойки, тёмные дуги и прозрачные окна барабанов; края плавно соединяются с общей рамой. Маска общей рамы заменяет целые небольшие полосы, поэтому неподвижных вырезов в форме стрелок больше нет. Бумага барабана находится под восстановленным металлом. Дополнительные PNG не создавались.

Каждая стрелка только поворачивается вокруг крепления: угол отвода 18°, поступательной тряски нет. По просьбе пользователя ход ускорен: для Topic — 3 хода, Format — 5, Angle — 6 (прежде 2/3/4); количество выбирается примерно по одному ходу на 5 позиций ленты. Отвод занимает 70% перемещения цикла, возврат — 30%, с плавным началом и окончанием обеих фаз. Времена вычисляются из кривой движения барабана, поэтому начало и торможение растягивают ходы. В текущих профилях каждый отвод длится более 190 мс, возврат — более 85 мс. В последние 80 мс стрелки неподвижны, без дополнительного щелчка и отскоков. Обе стрелки одного барабана завершают работу вместе с ним: на 1480 / 1960 / 2440 мс.

Анимации привязаны к той же временной шкале и cleanup, без отдельного таймера результата. При завершении и прерывании указатели возвращаются в исходное положение; reduced motion не запускает этот эффект. Ошибка одного декоративного слоя не блокирует остальной цикл. Внешний вид вырезок и движения остаётся предметом браузерного просмотра.

## Проверки

Текущий тест по просьбе пользователя: движутся три стрелки — левая у Topic, левая у Format и правая у Angle. Остальные три неподвижны. Все шесть наконечников, крепления и ключевые кадры сохранены. Список `animatedPointerIds` в `src/motion/pointerMotion.ts` содержит `left`, `middle-left-format`, `right`; добавление других ID возвращает их движение. Проверки подтверждают точный набор движущихся стрелок и остановку каждой вместе со своим барабаном.

Пройдены TypeScript, production-сборка с `/reading-roulette/`, аудит текущих каталогов и [проверки шага 9](verification.json): 60 проверок, 5 сценариев указателей, 6 сценариев колёс, 7 сценариев клавиш, 10 сценариев барабанов, 729 переходов, 11 сценариев основной кнопки и 9 сценариев копирования. Дополнительно проверены 495 сочетаний настроек и точная передача 13 365 промптов тестовому writer. Все 21 проверяемый HTTP-ресурс доступны.

Для колёс проверены монотонность скорости/позиции, общая шкала, остановка на 2440 мс, сохранение фазы при пяти моментах прерывания и следующем запуске, forced finish/cancel, watchdog, ошибка барабана, отсутствующий/ошибочный API колеса и 50 последовательных циклов. Для указателей проверены 3/5/6 ходов, плавные фазы, соответствие кривой барабана, правильное направление отвода обеих сторон, точный возврат в ноль, корректность ключевых кадров, последовательность остановок, cleanup, watchdog, ошибки и повторный setup. Остальные слои сцены сравниваются со статичным эталоном; оригинальные группы колёс дополнительно сравниваются после удаления слоя насечек. Для адаптированной рамы проверены исходный PNG, координаты SVG, шесть отдельных наконечников, четыре неподвижных крепления, четыре участка восстановленного фона и отсутствие треугольных вырезов в маске общей рамы. Байты всех 14 PNG и шрифта сохранены, CSS сцены не менялся.

Это проверки исходников, SSR-разметки и исполнения с тестовыми часами/Animation. Они не доказывают качество движения, FPS, поведение реального DOM или системного clipboard. Попытка подключения встроенного Browser завершилась EPERM при realpath browser-client.mjs; внешний браузер не запускался.

Для просмотра: открыть рабочую ссылку при обычном масштабе → несколько раз нажать SPIN → проверить движение насечек при неподвижных осях, плавное торможение и отсутствие скачка между запусками. Затем изменить ширину окна во время SPIN и повторить. Копирование и настройки должны снова становиться доступными после финала. Установка reduced motion должна давать мгновенный результат без вторичного движения.
