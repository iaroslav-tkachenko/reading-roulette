## Что изменено

Основной App теперь собирает принятую сцену из нативных React-компонентов RoomBackdrop, MachineScene и PromptSheet. Отдельные изображения находятся в src/assets/reading-machine; Vite включает их и локальный шрифт в production-сборку с корректным базовым путём. Сохранена лицензия шрифта.

Графика не перерисовывалась: все 14 PNG совпадают с эталоном побайтово. Сохранены 42 растровых экземпляра, 19 отдельных клавиш с отдельными буквами, 3 цилиндра, два колеса, рама, корпус и лицевая часть SPIN. Подписи и иконки остаются SVG/HTML, весь интерфейс не вставлен одной картинкой.

Начальное состояние: English / B1+ / Medium и Travel / Short story / Unexpected discovery. Полный промпт сформирован существующим buildPrompt и совпадает с принятым образцом. Лист естественно переносится и прокручивается вместе со страницей; видимая щель и тень у входа сохранены.

У комнаты и машины общая доступная ширина через контейнер #root. Это учитывает ширину вертикальной полосы прокрутки, в отличие от прежнего смешения 100vw для фона и 100% для машины. Граница стола зависит от того же масштаба и движется вместе со всей сценой. Внизу приложения убраны технические ссылки галереи, пространство под листом сохранено.

На этом шаге поля, SPIN, Copy prompt и How to use — статичные изображения/надписи. Анимация и взаимодействия подключаются на следующих этапах. Предыдущие App.tsx, App.css, index.css и index.html сохранены в before/. Каталоги, генератор, селектор и прежние компоненты/модуль анимации сохранены в исходниках. Статичный макет не менялся.

## Исправление масштаба после переноса

2026-10-11: в приложении отсутствовало общее правило эталона `.artboard>svg{display:block;width:100%;height:auto}`. Скрипт переноса брал CSS начиная с `@font-face`, а это правило находилось раньше. В результате SVG оставался шириной 1536 CSS-пикселей даже в более узком контейнере, выходил за кадр и сдвигал лист вниз.

В App.css восстановлено соответствующее правило для `.reading-scene .scene-artboard>svg`. Исправлен также migrate-artwork.mjs. Теперь ширина SVG равна ширине сцены, высота сохраняет исходные пропорции, а встроенный строчный зазор под SVG отсутствует. Эталон и графические слои не менялись.

В verify.mjs добавлены отдельные проверки размеров SVG в исходном CSS и production CSS. Проверка исходного CSS до исправления падала на этой ошибке; после исправления все 20 проверок проходят. TypeScript и сборка с `/reading-roulette/` также проходят. Состояние до исправления сохранено в before-scale-fix/. Визуальная проверка во встроенном Browser остаётся недоступна из-за EPERM.
