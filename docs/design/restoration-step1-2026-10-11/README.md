## Всё, что изменено в этом шаге

1. Пересобрана responsive-композиция: desktop-контент ограничен 1120 px вместе с полями; для desktop высотой до 780 CSS px применяется более компактная компоновка шириной до 1024 px.
2. How to use на desktop размещён в правом верхнем углу без отдельного высокого ряда. Уменьшены заголовок, отступы и промежутки; добавлена тонкая декоративная линия под названием. Подзаголовок сохранён.
3. Бордовая задняя часть, рисованная рамка и более широкая клавиатурная площадка соединены в общую композицию. Уменьшены высота и поля корпуса; сохранены тёмные опоры.
4. Панель native-настроек получила более компактные поля, бумажную поверхность, металлическую оправу и декоративные винты. Настоящие интерактивные области остаются не ниже 48 CSS px; значения select — 16 px.
5. Подготовлен отдельный рисованный металлический каркас reel-cradle-v1.png со скобами, валами, винтами и прозрачным центральным отверстием. Он создан встроенным ImageGen с v09 как style reference, без UI-текста, бумаги и контролов.
6. Создан reel-cradle-display.svg с viewBox по видимым alpha-границам и неизменёнными PNG-байтами внутри. Новый каркас подключён вокруг живых барабанов через border-image; CSS приглушает его насыщенность.
7. Бумажные окна получили цилиндрический силуэт, непрерывную светотень и линии у соседних полос. Плоские отдельные карточки заменены общей открытой механической композицией с HTML-табличками Topic / Format / Angle.
8. Добавлены неподвижные вертикальные крепления, винты и указатели у барабанов. Движущиеся ленты и их refs сохранены.
9. У колёс удалён scaleX(.68). Контейнер и вращающаяся часть имеют квадратную геометрию с aspect-ratio: 1; изображения используют object-fit: contain. Размеры desktop/tablet согласованы с новым корпусом.
10. Поверх вращающихся колёс добавлены неподвижные центральные hub-элементы. Оси и крепления находятся вне узлов, к которым применяется WAAPI-вращение.
11. Все 19 клавиш сохранены: QWERT / ASDFG и YUIOP / HJKL. Их изображения сохраняют пропорцию 989:1059; размеры desktop, короткого desktop и tablet уменьшены согласованно.
12. Буквы центрируются на светлой лицевой поверхности, а не по общей картинке с тёмной боковиной. Read-only анализ ярких ivory-пикселей master дал центр 49.93% / 39.21%; CSS использует 50% / 39.2% с translate(-50%, -50%). Буква и изображение остаются детьми одного движущегося keycap. Оптическая оценка реальных glyphs в браузере ещё нужна.
13. SPIN получила неподвижную металлическую оправу, тёмное углубление и непрозрачную подложку движущейся лицевой части. Общие hover/active-правила бумажных кнопок теперь явно исключают SPIN: ранее более специфичное общее active-правило могло перекрашивать recess в светлый цвет. Дефект в реальном браузере не воспроизведён; характер нажатия и его полная проверка остаются шагом 2.
14. Бумажный preview сужен, заведён в выходную щель и оформлен тенью у выхода, бумажной светотенью и неровным нижним краем. Уменьшена карточная обводка textarea. Полный prompt доступен внутри прокручиваемого preview; высота на коротком desktop — 100 px, на обычном — 126/166 px, на mobile — 180/220 px.
15. Copy prompt перенесена в paper-header справа от Prompt preview и перед textarea. Кнопка находится вне текстовой прокрутки. На 320 px она переносится отдельной строкой вверху листа; на остальных ширинах разрешён естественный перенос, если строка не помещается.
16. Ready/spinning-status оформлен спокойнее; подтверждения success/updated сохраняют отдельное оформление, ошибка — собственный контур и текст. Высота сообщений растёт по содержимому.
17. На mobile сохранены две строки настроек, вертикальные барабаны и вертикальная прокрутка страницы. Декоративные клавиши и боковые колёса скрываются ниже 768 px, как в исходной responsive-спецификации. Нет общего scale/zoom страницы или глобального overflow:hidden.
18. Существующая анимация подключена к новым деталям без изменения rouletteMotion.ts: быстрые 16/23/30 проходов, остановки 1480/1960/2440 ms, движение Q/S/O/J и колёс сохранены.
19. Существующий check-react-motion.mjs дополнен проверками структуры верхнего Copy, неподвижных hubs/mounts и общего родителя изображения с буквой у всех 19 keycaps. Добавлены необязательные путь и дата отчёта, чтобы новый запуск не перезаписывал исторический JSON. Новый запуск содержит 13 групп сценариев.
20. Сохранены исходные версии пяти затронутых текстовых файлов в before/, начальный git status, точный ImageGen prompt, alpha/hash-проверка artwork, отчёт motion, HTTP-проверки и лог финальной сборки.
