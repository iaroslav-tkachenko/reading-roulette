# Исправления после локализации и проверки на телефоне

Дата: 2026-10-12. Изменения сохранены отдельным локальным коммитом поверх `47da8bb`; публикация не выполнялась.

Рабочая ссылка для телефона в той же сети Wi-Fi: [открыть Reading Roulette](http://10.23.109.207:5175/reading-roulette/). Preview обслуживает собранный `dist` с базовым путём `/reading-roulette/`.

## Что изменилось

- В справку возвращено **4,300+ Reading ideas / 4 300+ Идей для чтения**. Объединение допустимых Topic × Format × Angle по 45 настройкам CEFR/длины даёт 4 310 уникальных троек; языки и настройки повторно не учитываются. Аудит сверяет число с `src/data/catalogStats.ts`. На ширине до 420 px число и подпись занимают отдельный ряд, языки и уровни стоят ниже.
- Удалена дополнительная строка верхних кнопок, которая при ширине 901–1280 px опускала всю сцену. На телефоне заголовок, справка и язык стоят в одном ряду. Справка обозначена вопросительным знаком с доступным именем; на компьютере подпись RU сокращена до «Инструкция». Порядок «справка, язык» и фиксированные размеры оставляют переключатель EN/RU на одном месте. Размер клика остаётся не меньше 44 px.
- В настольных окнах высотой до 700 px уменьшены верхний отступ бумаги и оформление Copy, сохранив размер клика 44 px. Это поднимает Preview и Copy на 1280×640.
- Русская кнопка подписана «Крутить», во время цикла «Крутим…». Иконка и подпись центрируются одной flex-группой на обоих вариантах сцены. Настольный корпус и hit target сохранены.
- Добавлены локальный Cyrillic subset EB Garamond для кириллических заголовков и кнопок и локальный JetBrains Mono для промпта. Исходный EB Garamond содержал только латиницу. Текст промпта на телефоне имеет 16 px; автоматическое увеличение текста ограничено через `text-size-adjust: 100%`, пользовательский zoom доступен. [Источники и лицензии](../../../../src/assets/fonts/README.md).
- Мобильный текст барабанов уменьшен с 22 до 20 SVG px; вертикальный шаг с 22 до 21. В движении и покое используется общий renderer.

## Проверки итоговой сборки

`pnpm build --base=/reading-roulette/` прошёл, включая TypeScript. Все браузерные проверки ниже запускались по ссылке LAN на итоговом production build в изолированном headless Chromium 153.0.8010.12.

- [201 проверка размеров, поведения и шрифтов](verification.json), [скрипт](check.mjs): EN/RU, 320×568, 360×560, 390×600, 412×640, 390×844, 768×1024, 900×700, 844×390; быстрые нажатия и изменение доступной высоты во время SPIN; desktop 901/1024/1170/1280/1366/1536 px; положение заголовка, EN/RU-кнопок, Preview/Copy; посадка обычной и занятой подписи SPIN.
- [Геометрия всех 200 мобильных EN/RU-подписей](label-bounds.json) измерена браузером. Ни одна не выходит за окно барабана.
- CDP `CSS.getPlatformFontsForNode` подтвердил фактический локальный шрифт для кириллических glyphs в промпте, заголовке промпта и кнопке «Крутить». Свойство `font-family` само по себе не считается таким доказательством.
- [Аудит локализации](localization/automated.json): 4 310 идей, 419 полей каталога, 149 334 RU-промпта, 495 настроек чтения; сохранение комбинации и настроек при переключении языка.
- [17 браузерных сценариев локализации](localization/browser.json): EN/RU, сохранение выбора, клавиатура, справка и возврат фокуса, SPIN, reduced motion, недоступное хранилище и Copy через тестовый writer. Ошибок страницы и консоли нет.
- [151 общая браузерная регрессия](regression/browser-verification.json): 13 конфигураций, фокус, быстрые клики и удержание Enter, согласованный финал барабанов, resize и смена компоновки, reduced motion до/во время SPIN, ошибка Animation API и watchdog. Ошибок браузера нет. Скрипт теперь дожидается события `matchMedia` и обновления React перед измерением после resize; первоначальное несоответствие на 901 px оказалось гонкой проверки.

| Доступная область страницы | Язык | Нижний край SPIN | Нижний край Copy |
| --- | --- | --- | --- |
| 320×568 | EN/RU | 446 px | 528 px |
| 360×560 | RU | 411 px | 493 px |
| 390×600 | RU | 415 px | 496 px |
| 390×540 после resize | RU | 415 px | 496 px |

Высота здесь означает область страницы после браузерных панелей, а не физическую высоту экрана телефона. В альбомной ориентации 844×390 используется обычная вертикальная прокрутка.

Скриншоты просмотрены: [RU 390×600](mobile-ru-390x600.png), [справка RU 320](help-ru-320.png), [RU desktop 1170×640](desktop-ru-1170.png). Предыдущие доказательства сохранены в соседних каталогах; копии файлов до этих правок находятся в `before/`.

Физический Android, Safari и screen reader на этом этапе не проверялись. Системный буфер Windows и нативный zoom проверялись на исходном шаге 11; в этом повторном запуске clipboard использует тестовый writer. Встроенный Browser остаётся недоступным из-за EPERM. Зависимости приложения и исходные изображения не изменены.
