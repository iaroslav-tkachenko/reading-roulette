# Мобильный первый экран

Правка от 2026-10-12 после проверки пользователем на телефоне. Цель: поднять SPIN, Prompt preview и Copy prompt за счёт меньшей высоты блоков.

## Изменения

- Заголовок 28 px, How to use 13 px с меньшей иконкой и рамкой. Нативные области нажатия остаются не меньше 44 px.
- Уменьшены отступы шапки, корпуса, настроек и листа. На экранах высотой до 700 CSS px скрывается только подзаголовок Try your luck. На более высоких экранах он сохраняется.
- От ширины 360 px настройки расположены в один ряд. На 320 px язык остаётся отдельной строкой. Настройки доступны сразу, без дополнительного окна.
- Три окна барабанов имеют шаг 78 вместо 120 SVG px. Общая геометрия используется рисунком, неподвижными подписями и движущимися лентами. Подписи переносятся; их фактический размер на 320 px остаётся больше 16 CSS px.
- SPIN имеет высоту 48 px. Заголовок промпта 20 px; Copy сохраняется рядом с ним, с переносом текста в узких окнах. Основной текст промпта остаётся 16 px.

## Проверки

Окончательная сборка проверена по сетевому адресу `http://10.23.109.207:5175/reading-roulette/` в Chromium 153.0.8010.12. Это действующий на момент проверки локальный адрес, требующий той же Wi-Fi сети и работающего сервера.

**133 проверки** в [check.mjs](check.mjs), результат в [verification.json](verification.json). Два языка интерфейса, восемь размеров окна для каждого языка, быстрые касания, изменение высоты во время SPIN, соответствие подготовленного результата промпту, справка и возврат фокуса. Все 200 английских и русских подписей измерены через реальный SVG-компонент и помещаются в меньшие окна, включая область анимации. [Границы текста](label-bounds.json).

Нижние границы кнопок и заголовка, CSS px от верха страницы без прокрутки:

| Видимая область | SPIN | Заголовок промпта, EN / RU | Copy, EN / RU |

| 320×568 | 475 | 555 / 555 | 556 / 556 |
| 360×560 | 430 / 446 | 496 / 526 | 506 / 527 |
| 390×600 | 450 | 515 / 529 | 526 / 531 |

При 390×844 в первоначальном отчёте шага 11 SPIN заканчивалась на 767 px, Copy на 921 px. После уплотнения при том же размере: 473 и 549 px соответственно, с видимым подзаголовком.

Дополнительно повторены **151 браузерная проверка** исходного шага 11 на окончательной сборке: фокус, быстрые клики и клавиатура, resize, смена компоновки, reduced motion, отказ Animation API, watchdog, ручное выделение промпта. [Отчёт](regression/browser-verification.json). Исходные отчёты и изображения шага 11 сохранены; общий скрипт теперь принимает `READING_TEST_OUTPUT_DIR` для отдельного сохранения повторных проверок.

TypeScript и production build прошли. `git diff --check` по изменённым в этой правке исходным файлам прошёл. Общая проверка рабочего дерева обнаруживает два ранее существовавших пробела в `SpinControl.tsx`, который этой правкой не редактировался.
