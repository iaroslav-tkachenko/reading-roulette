# EN/RU: переключатель языка и русская типографика

Дата: 2026-10-11. Реализовано локально 2026-10-12; фактический вид и проверки — в [отчёте](../localization/IMPLEMENTATION.md). Основание: [продуктовая спецификация](../localization/SPECIFICATION.md).

## Контрол возле How to use

Сохранить стилистику существующей сцены v10: тёмный фон кнопки, светлая обводка, тёплый текст, спокойный hover и отчётливый focus. Справку и выбор языка объединить в общий HTML-контейнер. Слева разместить `[флаг EN ▾]`, справа — `[? How to use]`; для RU — `[флаг RU ▾]` и `[? Как пользоваться]`.

Флаг EN: Великобритания; RU: Россия. Флаг рисуется небольшим локальным SVG и всегда сопровождается EN/RU. Не полагаться на emoji: целевой вид должен быть одинаково проверяемым в Windows. Иконки декоративные (`aria-hidden`); доступное имя включает выбранный язык. Размер иконки около 20×14 px, скругление небольшое, код читабельный. Контрол имеет область нажатия не меньше 44×44 CSS px.

Ширина справки должна вмещать «Как пользоваться». Текущий HelpButton содержит фиксированный SVG `153×41` и английский текст на заданных координатах: простая подстановка русской строки может обрезать её. Предпочтительно перенести подпись в HTML с гибкой шириной, сохранив визуальное оформление и семантику настоящей кнопки. Не уменьшать русский текст до нечитаемого размера для сохранения английской ширины.

## Открытый список

Панель закреплена под кнопкой, выравнивается по её краю, остаётся внутри viewport и выше SVG машины и листа. Ориентир ширины 170–200 px, padding 6–8 px, каждая строка не ниже 44 px. Строки: флаг + English, флаг + Русский; справа галочка у текущего значения. Названия языков всегда на собственном языке.

Предлагаемая семантика: обычная кнопка `aria-expanded`, `aria-controls`, `aria-haspopup="listbox"`; список `role="listbox"` с именем Interface language / Язык интерфейса, варианты `role="option"` и `aria-selected`. Следовать одному полному шаблону клавиатурного управления, не смешивать menuitem с option. Переключение запускает Enter/Space или клик по варианту; перемещение стрелками само по себе язык не меняет.

Enter/Space на кнопке открывает список и переводит фокус на активный вариант. Стрелки вверх/вниз перемещают фокус, Home/End выбирают первый/последний вариант для фокуса. Escape закрывает список и возвращает фокус кнопке. Tab закрывает список и продолжает обычный Tab-порядок. Клик снаружи закрывает список без принудительного возврата фокуса; после подтверждения варианта фокус возвращается кнопке. Открытие справки, старт SPIN и изменение раскладки закрывают список.

Во время подготовки/движения SPIN кнопка имеет disabled и локализованную подсказку «Язык можно изменить после остановки барабанов». Обработчик контроллера тоже проверяет блокировку. Справка сохраняет собственное модальное поведение; новый контрол не должен перекрывать открытый dialog.

## Узкий экран

В исходной базе help на узких экранах был закреплён внизу справа. Актуальная compact-адаптация размещает общую группу в шапке: список открывается вниз и проверен внутри viewport; правила ниже описывают исходные варианты размещения. Два отдельных fixed-контрола будут конкурировать за одно место, поэтому использовать общий компактный контейнер. На телефоне список открывается вверх, учитывая safe-area; группа помещается на ширине 320 px без горизонтального скролла. Если нижняя группа перекрывает Copy/preview, предусмотреть резерв места или перенести группу в свободную область компактной шапки. Выбранное размещение проверить в реальном браузере до приёмки.

В текущем рабочем дереве развивается [CompactMachine.tsx](../../src/components/scene/CompactMachine.tsx). Его HTML-заголовок, кнопка SPIN, названия барабанов и общие MachineSettings требуют тех же переводов, что SVG desktop. При реализации сначала проверить фактическую точку переключения раскладки; не добавлять второй одновременно активный комплект контролов.

## Типографика и неизменность сцены

На барабанах использовать короткие русские подписи из [таблиц каталогов](../localization/CATALOG_TRANSLATIONS.md). Сохранять смысл, переносить по словам, сначала корректировать строки, затем при необходимости размер/межстрочный интервал. Проверить как минимум «Деньги и финансы», «Встреча IT-команды», «Последствия решения», «Разные точки зрения», «Подробное объяснение» в соответствующем контексте. Не обрезать смысл многоточием и не переводить подписи прямо во время пролистывания DOM.

В `DrumLabel` разбиение сейчас основано на количестве символов, а не измерении текста. Нужна проверка кириллицы и длинных слов на реальном размере; соседние строки тоже должны помещаться. В подготовленных анимационных рядах хранить ID или локализовать все labels до старта в зафиксированной локали. Не смешивать русскую итоговую строку с английскими соседями.

Проверить наличие кириллицы в локальном EB Garamond и подходящем системном fallback. Поддержка шрифта пока не проверена. Сохранить офлайн-ресурсы и не загружать шрифт с внешнего CDN. Изменение `lang`, доступных имён и скрытых резервных строк обязательно: английский текст с `aria-hidden` тоже влияет на ширину/высоту зарезервированной области.

Название Reading Roulette, декоративные буквы клавиш, материалы и анимационные тайминги сохраняются. Видимые «КРУТИТЬ»/«КРУТИТСЯ…» рисуются отдельным текстом поверх существующего artwork. Проверить, нет ли дублирующего текста внутри PNG; это задача визуального просмотра, по одним исходникам отсутствие встроенной надписи не установлено.

## Визуальная приёмка

Снять EN/RU для desktop idle, открытого списка, мобильного idle, мобильного списка и полной справки. Проверить 320/390/768/1366/1920 px, 100/125/150/200% zoom, длинные подписи, длинный preview и reduced motion. Проверка клавиатуры, screen reader и clipboard перечислена в [QA](../localization/QA.md). Данный файл не подтверждает, что макет уже отрендерен или протестирован.
