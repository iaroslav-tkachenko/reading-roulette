# Motion v2 preview

**2026-10-10: прототип обновлён до v2.** Реализованы 2.44 s, 16/23/30 проходов, остановки 1480/1960/2440 ms, быстрый ход оставшихся барабанов, ход лицевой части SPIN, два боковых колеса, волна четырёх декоративных клавиш и маленький мобильный язычок. [Спецификация](../MOTION.md), [проверки и ограничения](VERIFICATION.md). Это реализация в локальном прототипе; визуальное воспроизведение в браузере пока не подтверждено автоматической проверкой.

Отдельный локальный интерактивный прототип v2. Кабинет, корпус и клавиши нарисованы упрощённым CSS, без финальных художественных assets. Прототип не заменяет основной экран в src; общий продуктовый контракт Topic / Format / Angle сохраняется.

Актуальная схема прототипа — **Topic × Format × Angle**, обязательная для всех частей проекта; см. [принципы каталогов](../../CATALOGS.md). Angle — конкретная идея текста. Регистр, тон, жанр и перспектива задаются внутри инструкций; отдельного барабана Tone нет.

Запуск из корня проекта:

```powershell
pnpm dev --host 127.0.0.1 --port 5173 --strictPort
```

Открыть http://127.0.0.1:5173/docs/design/motion-preview/ . Локальная ссылка работает на компьютере с запущенным сервером; страница не опубликована. Если порт занят, выбрать другой явно и заменить его в адресе.

Что проверить вручную в v2:

1. Нажать SPIN: ход кнопки, быстрые ленты, остановки Topic / Format / Angle с интервалом 480 ms, полный prompt после 2.44 s. При остановке Topic две другие ленты ещё быстрые, а после Format Angle продолжает быстрый ход. На desktop двигаются колёса и четыре клавиши; на mobile они скрыты, остаётся маленький язычок.
2. Включить **Next spin: long labels** и снова SPIN: длинные тестовые значения, переносы и высота. Выключить для возврата к настоящим коротким каталогам на следующем вращении.
3. Включить **Without motion**: немедленный результат. Системный reduced-motion также учитывается; переключатель не отключает системное предпочтение.
4. Сузить окно до 390/320 px: барабаны перестроятся вертикально, кнопки останутся доступными.
5. Copy prompt копирует полный buildPrompt. При отказе браузера текст можно выделить вручную.

Прототип импортирует реальные каталоги, selectReadingCombination и buildPrompt из src. Длинные названия заменяются только в памяти demo; production-каталоги не меняются. Длинный Angle — `An unexpected change of plans`. Результат выбирается один раз: три random draws на тему, формат и совместимый ракурс. Декоративные Angle берутся из совместимого с подготовленным форматом пула. Повторы неизбежны при небольших стартовых каталогах; N означает число проходов, а не уникальных записей. Под preview отображаются измеренные обработчиками длительность и моменты остановок; это не измерение fps. Повтор итоговой комбинации разрешён.

Полный каталог из 30 ракурсов и правила совместимости согласованы в [ANGLES.md](../../ANGLES.md), но пока не перенесены в этот прототип. Полная комбинация и промпт выбираются до движения; для вычисления Angle не требуется задержка старта или ожидание остановки Topic / Format. Общий старт и последовательные остановки сохраняются. Число трёх draws описывает стартовую реализацию, а не ограничивает будущий алгоритм с весами семейств и фильтрами.

Правила диапазонов, матрица длины для 44 форматов, сброс недопустимого результата и подтверждение `Prompt updated` после допустимой смены настроек согласованы в [LEVELS_LENGTH.md](../../LEVELS_LENGTH.md). Они ещё не реализованы в этом прототипе: текущие настройки сохраняют стартовую комбинацию без фильтров и без нового эффекта. Числовые тайминги подтверждения в спецификации — требования будущей реализации, а не проверка текущей страницы.

Эта HTML-страница обслуживается Vite в dev-режиме и не включена в обычный production build. Для проверки TypeScript прототипа используется отдельный вызов tsc с DOM/Vite types. Миграция общего контракта на Angle затрагивает также основной UI и общую сборку промпта; hosting и Git history не меняются.

Автоматическая проверка координации без браузера: `node docs/design/motion-preview/check-motion.mjs`. Скрипт выполняет настоящий preview.ts и его импорты с имитацией DOM, часов и WAAPI; проверяет 12 сценариев и сохраняет [JSON](motion-v2-checks-2026-10-10.json). Он не проверяет CSS layout, маски, настоящие кадры анимации, clipboard или доступность браузера.
