# Проверка локального motion-прототипа

Дата: 2026-10-09.

Актуальный обязательный контракт — **Topic × Format × Angle**; см. [каталоги](../../CATALOGS.md). Прежний Tone заменён в основном UI, промпте и этом прототипе. Исторические проверки ниже сохранены отдельно от проверки миграции.

## Проверка миграции на Angle

- `pnpm typecheck` и `pnpm build` прошли. Из-за EPERM при доступе к существующим node_modules команды выполнены с разрешённой эскалацией; зависимости не переустанавливались.
- Отдельная TypeScript-проверка preview.ts и его импортов прошла.
- Одноразовая проверка перебрала 27 допустимых комбинаций стартовых каталогов и 4 860 промптов с текущими языками, уровнями и длинами. Topic / Format / Angle и их инструкции согласованы с выбранными записями; отдельной строки Tone нет.
- Проверены три draw на выбор, границы random source, 15 случаев недопустимых значений, допустимость повторов и 500 случайных результатов. Неизвестный angle ID и пустой допустимый набор дают явную ошибку.
- Проверены 37 локальных Markdown-ссылок в девяти документах и форматирование.
- На локальном Vite `http://127.0.0.1:5177/` получен HTTP 200 для основного HTML, App.tsx, angles.ts, selectReadingCombination.ts, HTML motion-прототипа и preview.ts. Преобразованные UI-модули используют Angle. Это проверка обслуживания модулей, а не воспроизведения UI.
- Browser снова остановился при импорте browser-client.mjs с `EPERM: operation not permitted, realpath`. Визуальное воспроизведение, переполнение, клавиатура, Clipboard API и поведение анимации после миграции в браузере не подтверждены.
- На момент этой проверки изменения были локальными; push и публикация не выполнялись. Позднейшая публикация стартового приложения описана в [DEPLOYMENT.md](../../DEPLOYMENT.md); motion-прототип остаётся локальным. Старые PNG остаются историческими референсами; их подпись Tone не является актуальным требованием.

## Историческая проверка исходного motion-прототипа до миграции

В исходной проверке использовалась ссылка http://127.0.0.1:5173/docs/design/motion-preview/ . Сервер запускается из корня проекта; инструкция в [README.md](README.md). Номер порта зависит от конкретного локального запуска.

Выполнено:

- Проверка TypeScript отдельно для preview.ts и его импортов: `pnpm exec tsc --ignoreConfig --noEmit --strict --noUnusedLocals --noUnusedParameters --target es2023 --lib es2023,dom --module esnext --moduleResolution bundler --types vite/client --skipLibCheck docs/design/motion-preview/preview.ts`.
- Локальный Vite запущен на 127.0.0.1:5173. После ошибки EPERM в ограниченном контексте запуск выполнен с разрешённой эскалацией; зависимости не переустанавливались.
- HTTP 200 для HTML, CSS, преобразованного TypeScript модуля, buildPrompt.ts и selectReadingCombination.ts. Основной модуль содержит обработчик spinOnce и обслуживается Vite.
- Проверена математика движения: три длительности 1000/1200/1400 ms с общим стартом 80 ms; остановки 1080/1280/1480 ms; суммы дистанций и непрерывность скорости на стыках разгона/хода/торможения.
- Проверены локальные Markdown-ссылки и контрольные суммы всех пяти сохранённых PNG; исходные изображения не менялись.
- Основное приложение src, зависимости и конфигурация не изменялись. Отдельная уже существующая правка PROJECT.md о каталогах оставлена без изменений.

Не подтверждено:

- Визуальное воспроизведение в браузере, реальные переносы/overflow на 320/390 px, focus и повторные клики.
- Clipboard API, доступность со screen reader, fps/Performance trace и сценарии прерывания в работающей вкладке.
- Видео или browser screenshot не создавались.

Причина: подключение встроенного Browser остановилось при импорте официального browser-client.mjs с `EPERM: operation not permitted, realpath`. Файл существует; повтор с file URL дал ту же ошибку. Внешний браузер автоматически не запускался, конфигурация Browser и его cache не менялись. HTTP 200 и TypeScript-проверка не считаются доказательством интерактивной browser QA.

Эта запись фиксирует проверенный технический запуск и ограничения; прототип доступен для ручной оценки по ссылке.
