## Реализовано

- Кабинет, бордовый корпус и основание, бумажные окна, отдельная бирюзовая SPIN, полная декоративная клавиатура **19 клавиш**: QWERT / ASDFG и YUIOP / HJKL. Декоративные буквы не кликабельны и не получают фокус.
- Motion v2: 16/23/30 позиций, общий старт, остановки 1480/1960/2440 ms; оставшиеся ленты продолжают быстрый ход после каждой остановки. Выбор комбинации и buildPrompt выполняются один раз до движения.
- Лицевая часть SPIN вместе с текстом/иконкой нажимается на 4 px desktop / 3 mobile; фокус остаётся на неподвижной кнопке. Pointerdown отображает нажатие сразу, отмена pointer возвращает её.
- Два колеса получают 540°/900°, четыре выбранные клавиши Q/S/O/J движутся волной внутри полной клавиатуры. При нормальном завершении ориентация колёс сохраняется, без обратного скачка. Фон, лампа, корпус и prompt неподвижны.
- На <768 px колёса/клавиатура скрыты, внутри корпуса появляется маленький язычок. На <640 px три барабана располагаются вертикально, SPIN и Copy на всю доступную ширину. Длинные подписи используют общий sizing-envelope, без ellipsis итогового значения; envelope сохраняется после остановки.
- Semantic результат и полный prompt обновляются вместе после последней остановки. При SPIN настройки и Copy временно disabled; повторные нажатия игнорируются синхронно, клавиша SPIN сохраняет фокус через aria-disabled.
- Copy использует полный актуальный prompt. Guard по попытке/revision исключает устаревший результат после SPIN/настроек/unmount. При недоступном Clipboard API остаётся выделяемый read-only preview и сообщение о ручном копировании.
- Изменение настройки сохраняет текущую starter-комбинацию, меняет prompt/helper сразу, показывает Prompt updated 1600 ms и акцент 120+240 ms без блокировки Copy. При неизменной строке нет эффекта. Сложные профильные правила допуска относятся к этапу 4.
- Desktop How to use — native details с бумажным popover и Close/Escape; mobile — native modal dialog с Close/Escape. Инструкция состоит из трёх согласованных шагов.
- Reduced motion выдаёт результат сразу, без лент и вторичных движений. Смена preference, скрытие вкладки и изменение ширины завершают подготовленный результат; watchdog 3200 ms восстанавливает пропущенный finish. Pagehide/unmount отменяют движение; BFCache восстанавливает idle.
