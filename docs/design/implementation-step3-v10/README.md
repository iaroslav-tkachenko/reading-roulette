# Шаг 3 — How to use

Дата: 2026-10-11. Локальная реализация поверх шага 10. Рабочая ссылка: http://127.0.0.1:5173/ . Собранный вариант: http://127.0.0.1:5174/reading-roulette/ . Публикация в этот этап не входит.

## Что сделано

В [App.tsx](../../../src/App.tsx) подключены [настоящая кнопка](../../../src/components/HelpButton.tsx) и [карточка инструкции](../../../src/components/HowToUse.tsx). После отзыва пользователя переработана иерархия: основной заголовок «Read with confidence» описывает пользу, а небольшой «How to use» стоит непосредственно перед тремя шагами. Вступление сокращено и набрано обычным начертанием; IELTS, Goethe-Zertifikat, DELE и DELF сохранены как примеры экзаменов. Ссылок и длинных тире в тексте нет.

Факты представлены тремя колонками: «11 / Languages», «A1 to C2 / Levels», «4,300+ / Reading ideas». Значения выделены размером и тёмным цветом, подписи набраны обычным начертанием. Убрана красная жирная строка; выровнены левые края заголовка и текста. Основная гарнитура карточки сохранена. Состояние до этой правки сохранено в [revisions/before-typography](revisions/before-typography/) вместе с исходниками, снимками и прежним браузерным отчётом.

Последняя согласованная правка: оба вводных абзаца используют один цвет `#10262b`. Она проверена по CSS и через `git diff --check`; сохранённые снимки и браузерный отчёт относятся к предыдущей правке типографики.

Карточка открывается через native `dialog.showModal()` в верхнем слое браузера. Фон затемняется, остальные контролы становятся недоступны для взаимодействия. Сцена, настройки, текущий промпт и позиция прокрутки сохраняются; при блокировке прокрутки компенсируется ширина полосы прокрутки.

Крестик, Escape и клик по фону закрывают справку. Перетаскивание или выделение из карточки на фон её не закрывает. При открытии фокус получает крестик. Tab и Shift+Tab перемещают фокус между крестиком и прокручиваемой областью текста; после закрытия фокус возвращается на How to use без прокрутки страницы. Карточка подписана через `aria-labelledby`, область текста имеет доступное имя.

На компьютере кнопка сохраняет координаты прежней SVG-иллюстрации. На ширине до 700 px она закреплена внизу справа и имеет область нажатия высотой 44 px. Это позволяет открыть справку даже при прокрутке длинного промпта. Карточка ограничена экраном, текст прокручивается внутри неё, крестик остаётся видимым. Общая адаптация машинки относится к шагу 11.

Справка доступна во время SPIN; текущая анимация завершается и обновляет промпт за карточкой. После закрытия управление восстанавливается.

## Повторный запуск

При работающем dev-сервере:

```powershell
$env:READING_PLAYWRIGHT_MODULE='D:\Dev\Projects\Language Tracker\node_modules\.pnpm\playwright-core@1.63.0\node_modules\playwright-core\index.mjs'
node docs/design/implementation-step3-v10/browser-checks.mjs
```

Можно указать другой установленный `playwright` или `playwright-core` через `READING_PLAYWRIGHT_MODULE`; без переменной скрипт импортирует `playwright`. Браузер должен быть установлен в настроенном Playwright cache. `READING_TEST_URL` переопределяет адрес dev-сервера.

Для регрессии нужны dev-сервер на 5173, production-preview на 5174 и свежая сборка с `/reading-roulette/`:

```powershell
pnpm build --base=/reading-roulette/
node docs/design/implementation-step9-v10/verify.mjs
```
