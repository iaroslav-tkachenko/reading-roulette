# Reading Roulette — проверка согласованной системы

Дата: 2026-10-09.

Статус: **шаг 7 — аудит согласованной продуктовой схемы и текущего стартового кода выполнен**. Каталоги и базовые ограничения согласованы между собой; проверки стартовой реализации прошли. Полная система ещё не внедрена, подробная таблица допустимых раскрытий не создана, ответы внешних моделей и интерактивный UI в этой проверке не валидировались. Это не приёмка готового полного MVP.

## Проверенные документы и данные

- 26 уникальных Topic с минимумами и ограничениями начальных раскрытий: [TOPICS.md](TOPICS.md).
- 44 уникальных Format в шести семействах, распределение 6 / 8 / 6 / 6 / 11 / 7: [FORMATS.md](FORMATS.md).
- 30 уникальных Angle в пяти группах по шесть: [ANGLES.md](ANGLES.md).
- Все 15 настроек уровня × 3 длины: 45 строк проверки; 1 980 проверок базового допуска Format / Level / Length: [LEVELS_LENGTH.md](LEVELS_LENGTH.md).
- Шесть строк весов семейств покрывают все 15 уровней; каждая даёт 100%, нулевые веса не возрождаются: [READING_FAMILIES.md](READING_FAMILIES.md).
- Все 44 формата имеют базовый статус из четырёх согласованных; новости и репортажи требуют sourced, график и визуальный отчёт используют training: [CONTENT_STATUS.md](CONTENT_STATUS.md).
- Профили уровня в Topic и длине совпадают, плюс/минус сохраняют собственные языковые инструкции. Проверены ID, диапазоны, матрица длины, локальные Markdown-ссылки и отсутствие конечных пробелов.

Автоматическая проверка метаданных: [audit-catalogs.mjs](validation/audit-catalogs.mjs). Полные результаты всех 45 настроек, 44 сценария и 12 граничных примеров: [catalog-audit-2026-10-09.json](validation/catalog-audit-2026-10-09.json). Сценарии — примеры для ревью, не полный production allowlist и не сгенерированные моделью тексты.

## Доступность форматов и баланс

Числа ниже учитывают минимумы форматов и матрицу длины. Это базовый набор **до** проверки конкретных раскрытий Topic / Angle, а не число гарантированно допустимых полных сочетаний.

| Содержательный профиль | Short | Medium | Long |
| --- | ---: | ---: | ---: |
| A1 | 15 | 11 | 10 |
| A2 | 29 | 25 | 19 |
| B1 | 41 | 37 | 29 |
| B2 | 44 | 40 | 32 |
| C1+ | 44 | 40 | 32 |

Базовые наборы не пусты для всех 45 настроек. Каждому формату соответствует рассмотренный сценарий с существующими Topic / Angle, проходящий минимумы на начальном уровне этого формата. Для новостей сценарий условен наличием реальных публикаций во внешнем чате: аудит не искал и не проверял конкретное событие.

Обнаруженные крайние случаи ожидаемы по согласованным правилам и не требуют менять веса или минимумы:

| Настройка | Причина | Применение правила |
| --- | --- | --- |
| A2- при любой длине | Содержательный профиль A1 исключает короткий отзыв A2; другие форматы мнений тоже выше порога | Исходные 5% мнений исключаются, остальные положительные веса нормализуются |
| A2 / A2+ с Long | Единственный доступный по уровню формат мнений — короткий отзыв — не допускает Long | Нормализация оставшихся 95%; мнения получают 0% |
| B1- с Long | Веса B1, но допуск содержания A2; короткий отзыв не допускает Long | Исключить исходные 10% мнений, нормализовать оставшиеся 90% |
| A1 с Long | Визуальное семейство представлено историей в картинках; описание одной картинки не допускает Long | Сохраняется 30% семейства, число форматов не определяет его вес |
| B2- | Содержательный профиль B1 | Эссе, письменные дебаты и визуальный отчёт B2 ещё недоступны |
| C1- | Содержательный профиль B2 | Форматы уже доступны, но теоретические раскрытия философии C1+ не открываются автоматически |

Например, A2 Long даёт приблизительно **21,05 / 15,79 / 0 / 26,32 / 15,79 / 21,05%** по порядку шести семейств. B1- Long — **27,78 / 22,22 / 0 / 22,22 / 16,67 / 11,11%**. Это расчёт по базовым доступным форматам; реальные исключения конкретных раскрытий могут дополнительно убрать семейство. Матрица исходных вероятностей не менялась.

При внедрении сначала определять доступные сочетания и затем применять веса семейств. Равномерный выбор из всех строк сочетаний исказил бы семейные доли из-за разного размера каталогов. Для сохранения баланса рекомендуется сначала выбирать доступное семейство по нормализованному весу, затем элементы внутри него. Точные вероятности тем и вариантов внутри семейства пока не утверждены; этот отчёт не вводит их скрыто. Визуальный порядок остановок барабанов не задаёт порядок алгоритма.

## Содержательные примеры

В машинном отчёте есть по одному рассмотренному сценарию для каждого из 44 форматов. Проверены существование ID, минимумы, базовый допуск трёх длин и положительный вес семейства; смысл и статус примеров просмотрены при авторинге. Примеры для разных семейств:

| Уровень | Topic / Format / Angle | Результат проверки замысла |
| --- | --- | --- |
| A1 | Дом / бытовой рассказ / обычный день | Конкретная взрослая бытовая ситуация, простой сюжет |
| A1 | Обучение / заполненная форма / первое знакомство | 4–8 полей, вымышленные данные; только Short |
| A1 Long | Обучение / расписание / ближайшие планы | 16–24 учебные позиции, без искусственного набора слов |
| A1 | Дом / картинка с описанием / что где находится | Учебная сцена, согласованные предметы и текст |
| A2 | Космос / фактологическая справка / первое знакомство | Базовые сведения о Луне, без астрофизических теорий |
| A2 | Город / карта / что где находится | Схема вымышленного района; реальный маршрут не имитируется |
| A2 | Искусство / короткий отзыв / обратная связь | Учебный отзыв о вымышленной книге, без ложного реального опыта |
| A2 | Город / новостная заметка / что изменилось | Требуются реальные найденные материалы; только Short / Medium |
| B1 | Город / детектив / важная деталь | Согласованная вымышленная загадка и подсказки |
| B1 | Работа / IT follow-up / решения и следующие шаги | Учебные договорённости либо строгая адаптация реальных заметок |
| B1 | Личные финансы / график / заметная закономерность | Явно учебные числа, совпадающие график и описание; без мнимой причинности |
| B1 | Культура / репортаж / что изменилось | Реальные материалы и атрибуция; никакого выдуманного присутствия |
| B2 | Философия / эссе / трудный выбор | Понятная этическая ситуация, тезис и контраргумент; без неподтверждённых доказательств |
| B2 | Бизнес / визуальный отчёт / заметная закономерность | Учебные данные, анализ и ограничения |

Для 12 граничных случаев программно проверены ожидаемые допуски и отказы. В частности, A1 Long не открывает философское эссе; A2 Long исключает новость; A1 исключает карту A2; B1- исключает график B1; B2- исключает визуальный отчёт B2; A1 не допускает ракурс «Распространённое заблуждение» B1.

Это проверка метаданных и примеров. Полный перебор смысла всех Topic × Format × Angle не проводился: подробные разрешённые ветки ещё предстоит написать. Внешние тексты, фактическая сложность языка, соблюдение объёма, прочитанные источники и соответствие сгенерированных изображений не проверены.

## Исправленные расхождения документации

- Общее правило свободного выбора перспективы рассказа приведено к согласованному Format: базово третье лицо, первое — по явному Angle.
- Регистр делового письма унифицирован как деловой.
- Общее правило учебных практических документов уточнено: обстоятельства могут быть вымышленными, предметные знания и шаги инструкции должны быть достоверными.
- Завершённые шаги 1–6 больше не обозначаются как будущие вопросы согласования. Ссылки ведут к каноническим документам решений.
- Частичный визуальный результат, строгость новостных источников и подтверждение локальной адаптации промпта разделены. Галочка не обещает генерацию изображения, достоверность фактов или копирование.

## Проверка существующего кода

Выполнено в этой проверке:

- `pnpm typecheck` — успешно.
- `pnpm build` — успешно; получена локальная production-сборка.
- Отдельная строгая TypeScript-проверка `docs/design/motion-preview/preview.ts` и его импортов — успешно.
- Одноразовая проверка текущего селектора: все 27 стартовых допустимых комбинаций, все 4 860 промптов по 4 языкам × 15 уровням × 3 длинам, 500 случайных выборов, границы random source, 15 недопустимых значений, допустимость повторов, неизвестная ссылка Angle и пустой допустимый набор — успешно.
- Проверены включение выбранных Topic / Format / Angle в промпт и отсутствие отдельной строки Tone. В локальном прототипе комбинация и промпт готовятся до запуска движения — подтверждено чтением кода.

Результат стартовых runtime-проверок: [runtime-audit-2026-10-09.json](validation/runtime-audit-2026-10-09.json). Для доступа к существующим node_modules pnpm сначала получил sandbox EPERM; повтор с разрешённой эскалацией прошёл. Зависимости не переустанавливались.

В этой проверке не запускались HTTP- и интерактивные browser-сценарии. Клавиатура, Clipboard API, screen reader, реальное воспроизведение анимации и новый эффект `Prompt updated` не подтверждены. Исторические browser/HTTP-границы остаются в [VERIFICATION.md](design/motion-preview/VERIFICATION.md); старые результаты не выдаются за текущие.

## Что остаётся для реализации

| Область | Согласовано | Текущий код / оставшаяся работа |
| --- | --- | --- |
| Каталоги | 26 Topic / 44 Format / 30 Angle | В коде 3 / 3 / 4; нужен перенос полных записей и миграция старых ID |
| Допуск | Минимумы и явные простые раскрытия | Селектор фильтрует Angle только по `format.angleIds`; нужны инструкции раскрытия и полный allowlist |
| Баланс | Шесть семейств и веса по 15 уровням | Семейств/весов в коде пока нет; нужен выбор после фильтрации, без искажения долей размером каталога |
| Длина | Профили и восемь моделей объёма | В коде единые диапазоны слов; нужны компактные, визуальные, полевые и списочные шаблоны |
| Статус | Четыре статуса, источники и пометки | В buildPrompt ещё универсальные «original text» и «return only reading text»; нужны условные инструкции и блоки результата |
| Настройки | Сохранение допустимого, сброс недопустимого | В коде комбинация сохраняется без проверки; нужны nullable-состояние результата, отключение Copy и явный SPIN после сброса |
| Подтверждение | Галочка и мягкий акцент после адаптации | Ещё не реализовано; нужны ревизии промпта, отмена эффектов и защита от старых clipboard callback |
| Анимация | Общий старт, три остановки, reduced motion | Есть отдельный стартовый прототип; основное приложение ещё без согласованной анимации |
| Языки | Ранее запрошены исходный топ-8 плюс русский, португальский и сербский | В коде четыре языка, трёх добавлений нет. Исходная восьмёрка не зафиксирована в проверенных файлах; не восстанавливать её догадкой. Нужен канонический список перед переносом |
| Единицы языка | Структурные ограничения при неоднозначном подсчёте слов | Нужны языковые шаблоны; численные диапазоны знаков не утверждены |

Чтение стартовых исходников также подтвердило, что они не реализуют согласованные ограничения сложности темы. Указание внешней модели «предпочитать простой язык» не заменяет отбор допустимого раскрытия до сборки промпта.

После переноса правил нужна отдельная интеграционная приёмка полного набора, UI и внешних результатов. В этой работе production-исходники, зависимости и Git history не менялись; выполнены сохранение решений, аудит и локальные проверки. На момент этого аудита push и публикации не было. Позднее пользователь разрешил их; актуальный процесс и проверка публикации описаны в [DEPLOYMENT.md](DEPLOYMENT.md).

## Повторение проверки документов

Из корня проекта:

```powershell
node docs/validation/audit-catalogs.mjs
```

Скрипт использует стандартные модули Node, проверяет Markdown-метаданные и рассмотренные сценарии, обновляет JSON-отчёт. Он не вызывает внешние модели, не выполняет поиск новостей и не заменяет тесты будущего алгоритма выбора.
