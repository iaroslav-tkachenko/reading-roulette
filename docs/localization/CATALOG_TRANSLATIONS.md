## Грамматика simpleAction / simpleFocus

Буквальная замена английского `{focus}` русским именительным падежом может дать неграмотную фразу. Предлагаемый русский шаблон действия использует отдельную тему после двоеточия или в кавычках: «Покажите привычную последовательность действий. Конкретная тема: {focus}.» Для каждой из 30 пар действий проверить подстановку всех допущенных начальных тем. Не вводить автоматическое склонение или перевод через сеть. Альтернатива — явные готовые формы по ID, если отдельному действию нужна другая грамматика.

## Слой данных

Переводы привязываются к стабильным canonical ID. Сначала `checkCombination` проверяет исходные данные и возвращает канонические объекты; затем отображение и buildPrompt получают тексты нужной локали по ID. Сейчас checkCombination специально заменяет переданные объекты каноническими: передача «переведённых клонов» до этой проверки потеряет перевод.

Не создавать два независимых комплекта allowlists и не заменять labels внутри канонических объектов при каждом переключении. Полнота EN/RU проверяется по одинаковым наборам ID, полям и существующим disclosure-профилям. Отсутствующая русская инструкция — ошибка подготовки, которую нужно обнаружить до выпуска; английская подстановка не считается завершённой RU-локализацией.
