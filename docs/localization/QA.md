# EN/RU: проверки и приёмка

Обновлено: 2026-10-12. [Навигация](README.md). Матрица приёмки; выполненные проверки и артефакты — в [IMPLEMENTATION.md](IMPLEMENTATION.md).

## Статус подготовки

- Подготовлены спецификация, карта файлов, UI-тексты, 100 пар catalog-labels, русский общий шаблон с условными правилами, план реализации и приёмки.
- Все 419 catalog-полей реализованы; автоматический аудит проверил 149 334 русских промпта и 495 настроек чтения.
- Проверены TypeScript, production build, существующий полный EN-аудит и 61 регрессия механики. Новые браузерные проверки используют изолированный headless Chromium и тестовый clipboard writer.
- Проверены восемь ширин 320–1920 px и размеры всех 100 русских подписей в desktop/compact. Системный clipboard, screen reader, нативный zoom, физический телефон и публичная версия остаются непроверенными.

## Критерии готовности

| № | Критерий |
| --- | --- |
| A1 | Первый визит EN; сохранённый RU восстанавливается сразу и согласованно |
| A2 | Возле справки доступны флаг + EN/RU и ровно English / Русский с текущим выбором |
| A3 | Весь активный UI, help, catalog-labels, доступные имена, tooltip и ошибки переведены |
| A4 | В RU нет случайно оставленных английских инструкций/описаний; условные ветки эквивалентны EN |
| A5 | Смена locale сохраняет settings/ID, не вызывает RNG и анимацию |
| A6 | Preview и последующее Copy содержат одну актуальную строку; старые ответы не подтверждают новый промпт |
| A7 | SPIN готовит rows/result/prompt в одной locale, выбор языка заблокирован до остановки |
| A8 | Combination=null сохраняет просьбу SPIN и выключенный Copy; прежняя идея не восстанавливается |
| A9 | Кириллица/длинные labels читаемы; desktop/mobile/zoom не перекрывают контролы |
| A10 | Клавиатура, focus, Escape/Tab, document.lang и modal help работают в EN/RU |
| A11 | Совместимость, веса, CEFR, объём и статусы сохраняются; сетевого перевода нет |
| A12 | Проходят необходимые регрессии и production build, интерактивная работа подтверждена браузером |

## Автоматические проверки

1. Полнота: ровно en/ru, одинаковые UI-ключи/параметры и наборы 26/44/30 ID. Все 419 текстовых полей, включая 119 disclosures и слоты `{focus}`. Пустые строки, лишние ID, пропуски и необработанные плейсхолдеры — ошибка. Повторно вычислить количества по текущей базе.
2. Содержательная эквивалентность EN/RU: те же диапазоны, structural counts, CEFR/profile, источники, visual/sourced и notices. Поиск EN-фрагментов вспомогательный: учитывать разрешённые имена/аббревиатуры и выполнять редактуру.
3. Состояния: ready EN → RU → EN; same-locale no-op; cleared → RU; invalid settings → clear → locale → SPIN; active run → delayed locale event; reduced motion; ошибка пересборки. Проверить revision/updateCount/spinCount и отсутствие selector-вызовов.
4. Clipboard: отложенный success/error после locale-change игнорируется, включая EN → RU → EN. Следующий Copy передаёт точный новый preview. Проверить rejected/unavailable и ручной fallback. Уже начатая системная запись не считается отменённой.
5. Промпты: 11 языков × 15 уровней × 3 длины × 2 locale = 990 настроечных ячеек до фильтрации. Это не число промптов: внутри каждой учитывать совместимые комбинации. Сохранить полный EN-аудит, добавить RU-покрытие всех ID/полей/веток/восьми volume-models. Размер полного двойного перебора измерить до запуска; не повторять его без нового покрытия.
6. Persistence: отсутствие/запрет storage, en/ru, повреждённое значение, успех/ошибка записи. Ошибка записи не ломает текущую locale. DOM lang и description соответствуют snapshot.

Использовать текущую инфраструктуру Node/assert; новый test framework не требуется. Проверки полноты, переходов и условных веток должны подтверждать поведение, а не только структуру новой реализации.

## Ручные сценарии

| Действие | Ожидаемый результат |
| --- | --- |
| Чистое предпочтение → открыть | EN, начальная валидная идея, английский промпт, lang=en |
| Открыть список мышью/клавиатурой | Два варианта, активный отмечен, фокус виден; стрелки без подтверждения не меняют locale |
| Выбрать RU на начальной идее | UI/help/labels/prompt русские; язык чтения EN, те же ID и B1+/Medium |
| Copy при RU + English | Вставленный текст равен preview; английский основной материал, русские meanings |
| RU + Russian | Русский основной материал и простые русские определения |
| EN + Russian | Английские UI/инструкции, русский основной текст, английские meanings |
| Japanese / Chinese | Относительная длина без придуманных норм знаков; fields/items сохраняют меру |
| Смена locale в empty state | Причина/просьба SPIN переведены, Copy выключен, скрытой выборки нет |
| SPIN при RU | Все соседние/пролетающие/итоговые labels русские; prompt/result commit вместе |
| Locale во время SPIN | Контрол и запоздалый обработчик заблокированы; после остановки доступны |
| Быстрые EN → RU → EN с Copy | Нет старого feedback у нового preview; итоговый Copy копирует итоговый язык |
| Help EN/RU | Полный перевод, region/имя, Escape/backdrop/focus; сцена не прыгает |
| Tab/Home/End/Escape/наружный клик | Поведение по дизайну, нет скрытого focus и бесконечного удержания Tab |
| Reload после RU | RU восстановлен без английского первого промпта |
| Запрет storage | Выбор работает в текущей вкладке; после reload безопасный EN |
| Clipboard unavailable | Переведённая ошибка и доступный selectable preview |
| Sourced/visual/training | Все специальные инструкции переведены, ограничения сохранены |
| Resize/hidden/reduced motion | Согласованное завершение SPIN; locale не застревает заблокированной |

Проверить 320/390/768/1366/1920 px, 100/125/150/200% zoom, длинный help и самый длинный label. Сохранить EN/RU-скриншоты реализации отдельно от исторических референсов. Проверить консоль, отсутствие сетевого перевода, флаги, кириллицу, открытие списка вверх на телефоне, отсутствие перекрытия Copy/preview. Провести отдельную проверку screen reader в EN/RU: доступные имена, lang и краткие live-объявления.

Исполнение промпта во внешнем AI-чате — отдельная содержательная проверка при соответствующем поручении. Проверки приложения подтверждают инструкции и UI, но не качество текста, источников или изображений внешней модели.
