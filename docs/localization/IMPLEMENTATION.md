# Реализация EN/RU

Дата: 2026-10-12. Статус: **реализовано и сохранено в локальной истории Git; push/deploy не выполнялись**. [Навигация](README.md).

Последующие изменения по отзыву пользователя: [компактная шапка, счётчик идей и кириллические шрифты](../design/implementation-step11-v10/ui-polish/README.md). Эти правки сохранены отдельным локальным коммитом; таблица ниже сохраняет результаты исходного этапа локализации.

## Поведение

Возле How to use / Инструкция находится кнопка с локальным SVG-флагом и EN/RU. На телефоне справка обозначена знаком вопроса с доступным именем «Как пользоваться». В списке два варианта: English и Русский. Первый визит всегда EN; явный выбор сохраняется локально и восстанавливается после перезагрузки. Недоступное хранилище не мешает переключению в текущей вкладке.

Меняется весь активный интерфейс основной и компактной сцены: настройки, названия языков, выбранные/соседние/пролетающие строки барабанов, справка, кнопки, helper, tooltip, доступные имена, сообщения и ошибки. Промпт сразу пересобирается на выбранном языке из той же комбинации. Настройки чтения и ID сохраняются, RNG и анимация не запускаются. Во время SPIN переключатель заблокирован в UI и контроллере.

Язык учебного текста остаётся отдельным. RU + English запрашивает английский материал и русские объяснения словаря; RU + Russian — русский материал и простые русские определения. Русские инструкции покрывают все 419 catalog-полей, 15 CEFR-настроек, восемь моделей объёма, статусы содержания, реальные источники, визуальные/частичные результаты и заключительную полезную лексику.

Смена locale повышает revision и сбрасывает feedback копирования. Отложенные ответы Clipboard API не подтверждают новый preview, включая EN → RU → EN. Уже начавшуюся запись в системный буфер приложение не обещает отменить; следующий явный Copy копирует актуальную строку.

## Устройство

- [src/i18n](../../src/i18n): тип/валидация locale, UI-словарь, статические RU-ресурсы, имена/формы 11 языков и локализованное оформление длины. Новых зависимостей и сетевого перевода нет.
- [buildPrompt](../../src/prompt/buildPrompt.ts) принимает третий аргумент locale с EN по умолчанию; [buildRussianPrompt](../../src/prompt/buildRussianPrompt.ts) применяет RU-шаблоны после канонической проверки.
- [Контроллер](../../src/motion/drumSpinController.ts) хранит locale со snapshot/prompt, атомарно меняет её и фиксирует в prepared run. ReadingSettings, eligibility, веса, числа и начальные ID сохранены.
- [ReadingFailure](../../src/types/readingFailure.ts) содержит машинный ключ/параметры; диагностические EN-строки остаются совместимыми с существующими аудитами, пользователь видит перевод.
- [InterfaceLanguageSelect](../../src/components/InterfaceLanguageSelect.tsx) реализует список, стрелки/Home/End, Escape/Tab, закрытие снаружи и фокус; HelpButton имеет гибкую HTML-подпись.
- Группа действий расположена справа от заголовка без дополнительной строки над сценой. Фиксированные размеры и порядок «справка, язык» сохраняют положение языка при EN/RU. Кириллические длинные слова получают размер, проверенный по реальной геометрии текста; локальные EB Garamond Cyrillic и JetBrains Mono устраняют системную подстановку шрифта.

В справке показано согласованное **4,300+ Reading ideas / 4 300+ Идей для чтения**. Аудит объединения допустимых Topic × Format × Angle по всем 45 настройкам CEFR/длины подтверждает 4 310 уникальных идей без умножения на языки. `verify.mjs` сверяет этот результат с `src/data/catalogStats.ts`; счётчик тем больше не используется в справке.

## Запуск

Dev: [http://127.0.0.1:5173/](http://127.0.0.1:5173/).
Production preview: [http://127.0.0.1:4173/reading-roulette/](http://127.0.0.1:4173/reading-roulette/).

Проверки можно повторить из корня проекта:

```powershell
node docs/localization/verify.mjs
$env:READING_PLAYWRIGHT_MODULE='D:\Dev\Projects\Language Tracker\node_modules\.pnpm\playwright-core@1.63.0\node_modules\playwright-core\index.mjs'
node docs/localization/browser-checks.mjs
$env:READING_TEST_URL='http://127.0.0.1:4173/reading-roulette/'
node docs/localization/browser-checks.mjs
```

Browser-checks использует уже установленный Playwright Core, изолированный headless Chromium и тестовый writer вместо системного clipboard. Эти средства не добавлены в зависимости приложения. Для повторного запуска на другом компьютере указать доступный установленный модуль; production-preview требует предварительной сборки и работающего preview-сервера.

## Ограничения

Встроенный Browser не загрузился из-за EPERM в browser-client.mjs. Поэтому реальные DOM/клавиатурные/визуальные проверки выполнены проектным запуском изолированного headless Chromium. Обычные пользовательские окна и профили не управлялись.

Системный clipboard, screen reader, нативный zoom, физические телефоны, Safari/Firefox и публичный HTTPS-сайт не проверены этим этапом. Отдельный вызов внешней модели для исполнения RU-промпта не выполнялся; проверены состав инструкций, правила и работа приложения. Публикация остаётся вне текущего поручения.
