# Локализация Reading Roulette: English / Русский

Спецификация: 2026-10-11. Реализация: 2026-10-12. Статус: **EN/RU реализовано локально; публикация не выполнялась**. Фактические изменения и проверки — в [IMPLEMENTATION.md](IMPLEMENTATION.md).

Задача пользователя: английский по умолчанию, русский как второй язык, компактная кнопка с флагом возле How to use, выпадающий выбор языка, перевод всего интерфейса и самого промпта. После подготовки документации пользователь поручил реализовать функцию локально.

Реализованное поведение: выбор Русский сразу переводит интерфейс, текущую комбинацию и инструкции промпта, сохраняя язык изучаемого текста, уровень, длину и ID выпавшего результата. Повторный SPIN нужен только для новой идеи или уже пустого результата. Промпт собирается локально из заранее подготовленных переводов; запрос к переводчику или модели не требуется.

## Основание и актуальность

Спецификация составлена по текущим локальным исходникам, включая незакоммиченные изменения. В них есть полный каталог 26 / 44 / 30, 11 языков чтения, отдельные HelpButton/HowToUse и разрабатываемая компактная раскладка CompactMachine. Часть старых README и отчётов ещё описывает пропущенную справку или стартовый каталог: при реализации нужно повторно сверить текущий код. Старые отчёты не доказывают состояние публичного сайта на дату этого документа.

Изученные точки входа: [App.tsx](../../src/App.tsx), [buildPrompt.ts](../../src/prompt/buildPrompt.ts), [контроллер SPIN](../../src/motion/drumSpinController.ts), [MachineSettings.tsx](../../src/components/scene/MachineSettings.tsx), [PromptSheet.tsx](../../src/components/scene/PromptSheet.tsx), [HowToUse.tsx](../../src/components/HowToUse.tsx), [совместимость](../../src/random/compatibility.ts), [языки чтения](../LANGUAGES.md).

UI-словарь, 100 подписей и все 419 текстовых полей каталогов подключены в [src/i18n](../../src/i18n). Русский общий шаблон и условные sourced/visual/training/length/vocabulary-блоки используются сборщиком промпта. Английские канонические данные и предметные правила сохраняются; переводы проверены отдельно от совместимости.

Реализация сохранена в локальной истории Git по поручению пользователя от 2026-10-12. Публикация остаётся отдельным этапом: push/deploy не выполнялись. Существовавшие и параллельно изменяемые файлы рабочего дерева сохраняются.
